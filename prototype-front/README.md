# Prototype local - On mange quoi ?

Ce dossier contient une reconstruction navigable du frontend montré dans la vidéo. Les données sont simulées localement : aucun compte, paiement, Wallet ou serveur externe n'est utilisé.

## Lancer sur Windows

Double-cliquer sur `LANCER-LE-PROTOTYPE.bat`.

Le site s'ouvre à l'adresse `http://127.0.0.1:5173/`. Garder la fenêtre de commande ouverte pendant la démonstration.

## Commandes manuelles

```powershell
npm install
npm run dev
```

Vérification de production :

```powershell
npm run build
```
